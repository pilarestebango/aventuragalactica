# aventuragalactica

A one-page wrapper that shows **ALBA & SOFIA ADVENTURE** full-screen at
`https://pilarestebango.github.io/aventuragalactica/`.

The game itself is not here: it lives in
[the-wedding-game](https://github.com/pilarestebango/the-wedding-game) under
`alba-sofia/`, and `index.html` loads it in a frame. Change the game there;
this repo only needs touching if that folder is renamed (`GAME_URL` in
`index.html`).
